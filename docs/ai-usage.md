# MI-használat

A projekt készítése során mesterséges intelligencia alapú eszközt alkalmanként, naplószerűen dokumentálva használtam. Az alábbiakban a főbb felhasználási esetek időrendben kerülnek bemutatásra.

## 2026.02 – Projekt indulása

- Ötletelés a jegyzetmegosztó platform funkcióiról
- Alap rendszerfelépítés (frontend, backend szétválasztás) átbeszélése
- Adatbázis entitások első verziójának megtervezése

## 2026.03 – Adatbázis és backend tervezés

- Segítség kérése relációk értelmezésében (pl. user–note kapcsolatok)
- SQL táblák struktúrájának finomítása
- API végpontok logikai felépítésének áttekintése

## 2026.04 – Fejlesztés közbeni problémák

- React.js működésével kapcsolatos kérdések tisztázása
- Autentikációs folyamatok (pl. Google login) megértése
- Hibakeresés és lehetséges megoldási irányok átbeszélése

## 2026.04 – Frontend és adatkezelés

- API hívások kezelése (axios használat)
- Állapotkezelési megoldások áttekintése
- UI működésének finomhangolása

## 2026.05 – Dokumentáció készítése

- README és telepítési útmutató megfogalmazásának segítése
- Biztonsági szempontok (XSS, input validáció) összegyűjtése
- Szakdolgozati szövegek stilisztikai javítása

## 2026.05 – Véglegesítés

- Dokumentációk átnézése és javítása
- Strukturális és megfogalmazási finomítások
- AI használat összefoglalása

## Megjegyzés

Az MI által adott javaslatokat minden esetben ellenőriztem és a saját döntéseim alapján alkalmaztam. A projekt megvalósítása önálló munkán alapul.
